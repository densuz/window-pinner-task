# window-pinner-task
"Tools ini merupakan aplikasi sederhana untuk melakukan pin pada task yang sedang aktif di Windows. Cara penggunaannya cukup mudah: pilih aplikasi yang ingin di-pin, lalu Klik tombol 'Pin'. Dengan demikian, aplikasi tersebut akan selalu berada di atas (stay on top) dan tidak tertutup oleh task lain. 100% telah diuji dan berfungsi dengan baik di Windows 11 Pro
